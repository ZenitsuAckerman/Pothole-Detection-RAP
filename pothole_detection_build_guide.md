## 2. Tool Stack (exact tools, why each one)

| Purpose | Tool | Why this one, given 5 hours |
|---|---|---|
| Dataset sourcing | **Roboflow Universe + `roboflow` Python SDK** | Pre-labeled, licensed, YOLO-export in one API call. Zero labeling time. |
| Detection model | **Ultralytics RT-DETR (`rtdetr-l.pt`)** | Satisfies "faithful RT-DETR implementation" constraint; Ultralytics API is a single `model.train()` call, COCO-pretrained weights included. |
| Training env | **Google Colab (T4 GPU) or local CUDA GPU** | Free, fast enough for 30 epochs on a few thousand images at 640px. |
| Experiment logging | **Ultralytics built-in CSV/plots + a `hyperparams.json` you write by hand** | Reproducibility constraint — don't rely on memory, dump exact config to a file the moment training starts. |
| Eval / metrics | **Ultralytics `model.val()`** + custom `eval.py` for per-class breakdown | Gives mAP50, mAP50-95, P/R out of the box; custom script needed for failure-case mining. |
| API framework | **FastAPI + Uvicorn** | Explicitly required by the PS; async-friendly, auto OpenAPI docs at `/docs` (useful for the reviewer). |
| Data validation | **Pydantic v2** | Clean request/response schemas, auto-validation, matches "code quality" scoring criterion. |
| Image handling | **Pillow + OpenCV (`opencv-python-headless`)** | Standard, reliable decode/resize/draw-box utilities. |
| LLM reasoning call (Part B) | **Anthropic API (`anthropic` SDK) or OpenAI SDK — one plain call, no framework** | PS explicitly bans LangChain/CrewAI/AutoGen. A raw `client.messages.create()` call is exactly "a hand-written decision layer." Use whichever key you have; code below is provider-agnostic with a thin wrapper. |
| Containerization (bonus) | **Docker** | 10% bonus criterion, ~15 min cost if you template it now. |
| Version control | **Git + GitHub** | Required deliverable. Commit after every phase, not just at the end — protects you if you run out of time. |
| Testing calls | **`curl` / Postman / FastAPI's built-in `/docs` Swagger UI** | Fastest way to prove both endpoints work for the "sample request/response" deliverable. |

## 5. Training (Hour 0:30–1:30)

```python
# training/train.py
import json, time, subprocess, platform
from ultralytics import RTDETR

CONFIG = {
    "model": "rtdetr-l.pt",
    "data": "../data/data.yaml",
    "epochs": 30,
    "imgsz": 640,
    "batch": 8,
    "device": 0,
    "seed": 42,
    "patience": 15,   # early stop if val mAP plateaus
}

def main():
    start = time.time()
    model = RTDETR(CONFIG["model"])
    results = model.train(
        data=CONFIG["data"],
        epochs=CONFIG["epochs"],
        imgsz=CONFIG["imgsz"],
        batch=CONFIG["batch"],
        device=CONFIG["device"],
        seed=CONFIG["seed"],
        patience=CONFIG["patience"],
        project="runs/train",
        name="pothole_rtdetr",
    )
    elapsed = time.time() - start

    # Reproducibility artifact — write this immediately, don't rely on memory later
    log = {
        **CONFIG,
        "wall_clock_seconds": elapsed,
        "python": platform.python_version(),
        "gpu": subprocess.getoutput("nvidia-smi --query-gpu=name --format=csv,noheader"),
        "ultralytics_version": subprocess.getoutput("pip show ultralytics | grep Version"),
    }
    with open("hyperparams.json", "w") as f:
        json.dump(log, f, indent=2)
    print(f"Done in {elapsed/60:.1f} min. Best weights at runs/train/pothole_rtdetr/weights/best.pt")

if __name__ == "__main__":
    main()
```

## 6. Evaluation + Failure Case Mining (Hour 1:30–2:15)

```python
# evaluation/eval.py
from ultralytics import RTDETR
import json

model = RTDETR("../training/runs/train/pothole_rtdetr/weights/best.pt")
metrics = model.val(data="../data/data.yaml", split="val")

report = {
    "mAP50": float(metrics.box.map50),
    "mAP50-95": float(metrics.box.map),
    "precision": float(metrics.box.mp),
    "recall": float(metrics.box.mr),
}
print(json.dumps(report, indent=2))
with open("val_metrics.json", "w") as f:
    json.dump(report, f, indent=2)
```

**Failure case mining** — run inference on the val set with `save_conf=True, save=True`, sort predictions by lowest confidence or visually scan `runs/detect/predict/` for:

1. Small/distant pothole missed entirely (scale sensitivity)
2. Water-filled pothole — reflection/glare causes false negative or double-detection
3. Shadow on flat road misclassified as pothole (false positive)
4. Motion-blurred frame — box localization is loose/wrong
5. Two adjacent potholes merged into one box (NMS threshold too aggressive)

For each: save the image with predicted + ground-truth boxes overlaid, write 3–4 sentences of root cause. Do this now, while the patterns are fresh — this section is graded at 15%, same weight as raw detection performance.

## 7. Part A — FastAPI Detection Endpoint (Hour 2:15–3:15)

```python
# api/schemas.py
from pydantic import BaseModel
from typing import List

class BoundingBox(BaseModel):
    x1: float
    y1: float
    x2: float
    y2: float

class Detection(BaseModel):
    class_name: str
    confidence: float
    box: BoundingBox

class DetectionResponse(BaseModel):
    detections: List[Detection]
    image_width: int
    image_height: int
```

```python
# api/detector.py
from ultralytics import RTDETR
from PIL import Image
import io
from schemas import Detection, BoundingBox, DetectionResponse

MODEL_PATH = "../weights/best.pt"
CONF_THRESHOLD = 0.25

class Detector:
    def __init__(self, model_path: str = MODEL_PATH):
        self.model = RTDETR(model_path)  # loaded once at startup, not per-request

    def predict(self, image_bytes: bytes) -> DetectionResponse:
        img = Image.open(io.BytesIO(image_bytes)).convert("RGB")
        results = self.model.predict(img, conf=CONF_THRESHOLD, verbose=False)[0]

        detections = []
        for box in results.boxes:
            xyxy = box.xyxy[0].tolist()
            detections.append(Detection(
                class_name=self.model.names[int(box.cls[0])],
                confidence=float(box.conf[0]),
                box=BoundingBox(x1=xyxy[0], y1=xyxy[1], x2=xyxy[2], y2=xyxy[3]),
            ))

        return DetectionResponse(
            detections=detections,
            image_width=img.width,
            image_height=img.height,
        )
```

```python
# api/main.py
from fastapi import FastAPI, UploadFile, File, HTTPException
from detector import Detector
from schemas import DetectionResponse
from reasoning import answer_question
from pydantic import BaseModel

app = FastAPI(title="Pothole Detection & Reasoning API")
detector = Detector()  # loaded once at process startup

@app.post("/detect", response_model=DetectionResponse)
async def detect(file: UploadFile = File(...)):
    if not file.content_type.startswith("image/"):
        raise HTTPException(400, "File must be an image")
    image_bytes = await file.read()
    return detector.predict(image_bytes)

class QuestionRequest(BaseModel):
    question: str

@app.post("/ask")
async def ask(question: str, file: UploadFile = File(...)):
    image_bytes = await file.read()
    result = answer_question(question, image_bytes, detector)
    return result

@app.get("/health")
async def health():
    return {"status": "ok"}
```

## 8. Part B — Reasoning Layer (Hour 3:15–4:15)

**No frameworks. Three hand-written functions: route → reason → guard.**

```python
# api/llm_client.py — thin, swappable wrapper, NOT a framework
import os
import anthropic

client = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])

def call_llm(prompt: str, max_tokens: int = 300) -> str:
    resp = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=max_tokens,
        messages=[{"role": "user", "content": prompt}],
    )
    return resp.content[0].text
```

```python
# api/reasoning.py
from llm_client import call_llm
import json

CONF_GUARDRAIL_THRESHOLD = 0.4
OUT_OF_SCOPE_KEYWORDS = ["depth", "how old", "cause", "when was", "material", "brand"]

DETECTION_KEYWORDS = ["how many", "is there", "count", "safe", "visible",
                      "present", "any pothole", "damage"]

def intent_router(question: str) -> bool:
    """Rule-based first; falls back to a single constrained LLM call only if ambiguous."""
    q = question.lower()
    if any(k in q for k in DETECTION_KEYWORDS):
        return True
    if any(k in q for k in ["what is", "who", "capital of", "weather"]):
        return False

    # Ambiguous — one explicit, constrained LLM call (not a chain, not an agent)
    prompt = (
        f'Question: "{question}"\n'
        "Does answering this question require analyzing objects detected in an image "
        "(counts, presence, positions of potholes)? "
        'Respond with ONLY valid JSON: {"needs_detection": true} or {"needs_detection": false}'
    )
    raw = call_llm(prompt, max_tokens=20)
    try:
        return json.loads(raw.strip())["needs_detection"]
    except (json.JSONDecodeError, KeyError):
        return True  # fail safe toward running detection rather than guessing blind


def is_out_of_scope(question: str) -> bool:
    q = question.lower()
    return any(k in q for k in OUT_OF_SCOPE_KEYWORDS)


def structured_reasoner(question: str, detection_response) -> str:
    summary = {
        "count": len(detection_response.detections),
        "confidences": [round(d.confidence, 2) for d in detection_response.detections],
        "boxes": [d.box.dict() for d in detection_response.detections],
        "image_size": [detection_response.image_width, detection_response.image_height],
    }
    prompt = (
        f"You are answering a question about an image using ONLY this structured "
        f"detection output (no other knowledge of the image):\n{json.dumps(summary)}\n\n"
        f'Question: "{question}"\n'
        "Answer in one or two plain-language sentences, grounded strictly in the data above."
    )
    return call_llm(prompt, max_tokens=150)


def answer_question(question: str, image_bytes: bytes, detector) -> dict:
    needs_detection = intent_router(question)

    if not needs_detection:
        return {
            "answer": call_llm(f"Answer briefly: {question}", max_tokens=100),
            "used_detection": False,
        }

    if is_out_of_scope(question):
        return {
            "answer": "Insufficient information: this model only detects pothole "
                      "presence and location, not attributes like depth, age, or cause.",
            "used_detection": False,
            "guardrail_triggered": "out_of_scope",
        }

    detection_response = detector.predict(image_bytes)

    if len(detection_response.detections) == 0:
        return {
            "answer": "No potholes were detected in this image with sufficient confidence.",
            "used_detection": True,
            "detections": [],
        }

    max_conf = max(d.confidence for d in detection_response.detections)
    if max_conf < CONF_GUARDRAIL_THRESHOLD:
        return {
            "answer": "Insufficient information: detections in this image fall below "
                      f"the confidence threshold ({max_conf:.2f} < {CONF_GUARDRAIL_THRESHOLD}), "
                      "so I can't answer confidently.",
            "used_detection": True,
            "guardrail_triggered": "low_confidence",
            "max_confidence": max_conf,
        }

    answer = structured_reasoner(question, detection_response)
    return {
        "answer": answer,
        "used_detection": True,
        "detections": [d.dict() for d in detection_response.detections],
    }
```

**Document one concrete "insufficient information" example for the memo**, e.g.:

> Q: "How deep is the pothole in this image?"
> → `is_out_of_scope` triggers on "how deep" → returns "Insufficient information: this model only detects pothole presence and location, not attributes like depth, age, or cause." *(This is correct because the detector outputs 2D bounding boxes only — depth is not observable from a single monocular image at all, let alone from box coordinates.)*
